OBS Safe VST3 Host — Windows x64 Public Trial
==============================================

Recommended for most users: Smart Setup.exe
---------------------------------------------
1. Close OBS Studio.
2. Run the newest:
     OBS-Safe-VST3-Host-v<VERSION>-Setup-x64.exe
3. For a normal OBS installation, keep Standard OBS Studio (recommended).
   Setup installs the plug-in into OBS's ProgramData plug-in layout.
4. For OBS Portable or a custom self-contained OBS folder, choose
   Custom / Portable OBS folder and select the OBS root containing:
     bin\64bit\obs64.exe
5. Click Install.
6. Start OBS Studio, open an audio source -> Filters -> + ->
   VST 3.x Plug-in (Safe Host).
7. Click Rescan Installed VST3 Plug-ins and choose an effect.

The runtime package contains:
  obs-safe-vst3.dll
  obs-safe-vst3-host.exe
  obs-safe-vst3-scanner.exe
  locale\en-US.ini

The smart installer does not install or modify OBS itself. If OBS is open,
Setup asks you to close it before copying files.

Portable ZIP / advanced install
-------------------------------
The portable ZIP is designed to be extracted directly into the OBS root:

  obs-plugins/64bit/obs-safe-vst3.dll
  obs-plugins/64bit/obs-safe-vst3-host.exe
  obs-plugins/64bit/obs-safe-vst3-scanner.exe
  data/obs-plugins/obs-safe-vst3/locale/en-US.ini
  README-FIRST.txt
  UNINSTALL-MANUAL.cmd

Uninstall
---------
The Smart Installer registers OBS Safe VST3 Host in Windows Installed Apps.

For a portable installation, close OBS and run UNINSTALL-MANUAL.cmd from the
OBS root, or remove only the project-owned files listed above.

Scanner behavior
----------------
The public trial scans standard Windows VST3 locations. Each discovered .vst3
bundle is probed in its own short-lived scanner child process. A hung probe is
terminated after its timeout and skipped. The resulting cache is stored under
the current user's LocalAppData folder and read by the OBS properties UI.

Use Custom VST3 bundle (optional) for a non-standard location.

Safety notes
------------
- Third-party VST3 DSP runs in obs-safe-vst3-host.exe, not obs64.exe.
- Scanning also occurs outside OBS, with a separate child probe per bundle.
- Process isolation is crash/hang containment, NOT a malware sandbox.
- The realtime OBS filter uses bounded waiting and keeps dry audio on timeout.
- The public trial attempts to restart a failed helper automatically.
- Windows x64, mono/stereo and float32 audio effects are the current target.

Public Trial limitations
------------------------
Not implemented yet:
- native VST3 vendor GUI;
- generic parameter controls;
- full component/controller state persistence;
- sidechain;
- VST3 instruments/MIDI;
- arbitrary multichannel and float64 fallback.

This release should therefore be treated as a compatibility/reliability trial,
not yet as a production daily-driver VST host.

CI / release validation
-----------------------
The Windows release pipeline validates:
- protocol tests;
- isolated host build;
- isolated scanner build and smoke execution;
- real OBS module compilation against pinned OBS/libobs 32.2.2;
- portable ZIP layout including scanner;
- Smart Installer compilation;
- silent install/uninstall into a synthetic portable OBS tree;
- SHA-256 checksums for published assets.

Real-world third-party VST3 compatibility still requires public testing.
