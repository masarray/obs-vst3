OBS Safe VST3 Host v0.6.0 — Windows x64
=========================================

What this installs
------------------
OBS Safe VST3 Host adds two OBS audio filters:

  VST 3.x Plug-in
  VST3 Rack

The Single filter hosts one VST3 effect in obs-safe-vst3-host.exe.
VST3 Rack hosts up to 8 serial mono/stereo Float32 VST3 effects in one
obs-safe-vst3-rack-host.exe process per Rack.

Installed files
---------------
  obs-plugins\64bit\obs-safe-vst3.dll
  obs-plugins\64bit\obs-safe-vst3-host.exe
  obs-plugins\64bit\obs-safe-vst3-rack-host.exe
  obs-plugins\64bit\obs-safe-vst3-scanner.exe
  data\obs-plugins\obs-safe-vst3\locale\en-US.ini

Recommended install
-------------------
1. Close OBS Studio completely.
2. Run OBS-Safe-VST3-Host-v0.6.0-Setup-x64.exe.
3. Confirm the OBS Studio root folder.
4. Start OBS Studio.

Use one VST3 effect
-------------------
1. Open Filters for an OBS audio source.
2. Add VST 3.x Plug-in.
3. Choose Installed plug-ins and select a compatible VST3 effect.
4. Open the vendor UI when needed.

Use VST3 Rack
-------------
1. Open Filters for an OBS audio source.
2. Add VST3 Rack.
3. In Properties, click Open Rack.
4. Search installed plug-ins and choose Add Effect.
5. Add/insert/reorder/enable/bypass/replace/remove up to 8 serial effects.
6. Use Open UI on a slot for its native VST3 editor.
7. Use Save As to create a named Rack preset. Load, explicit Update, Rename
   and Delete are available from the preset controls.

Preset load creates an independent working Rack. Normal edits after load do
not change the saved preset unless Update is explicitly selected. If a preset
references an unavailable plug-in, the slot can remain a Missing/pass-through
placeholder.

Portable install
----------------
Extract OBS-Safe-VST3-Host-v0.6.0-Windows-x64-Portable.zip directly into the
OBS root folder, preserving its directory structure. Read README-FIRST.txt.

Safety / scope
--------------
Third-party VST3 code is deliberately hosted outside obs64.exe. This is crash
isolation, not a malware sandbox. Only install plug-ins you trust.

v0.6.0 supports Windows x64, mono/stereo Float32 VST3 audio effects and a
serial Rack. It does not provide parallel graph routing, sidechain, MIDI/VST3
instruments, nested Racks, Float64/arbitrary multichannel, or a stable
macOS/Linux runtime.

Release binaries are currently not commercially Authenticode-signed, so
Windows may show Unknown publisher or a SmartScreen reputation warning.
Download only from the official GitHub Release and use SHA256SUMS.txt when you
want to verify integrity.
