v0.6.0 compatibility

Stable scope first. Broader claims only with evidence.

The Rack is now part of the normal product, but v0.6.0 intentionally stays inside a bounded Windows audio-effects scope.

Qualification

What was actually tested?

Release qualification combines deterministic Rack contracts, Windows builds, OBS loader checks and real user smoke testing.

CI

Deterministic Rack gates

Serial DSP, safety, topology, recovery baseline, Session Snapshot, editor lifecycle, browser, vendor editor, presets, P0 shutdown and P1 product-UI contracts.

OBS

OBS/package gate

Windows Compatibility builds the plug-in/helper/scanner/Rack, runs tests and scanner smoke, probes the module on official OBS 29.1.3, then validates portable and installer layout.

✓

Real OBS smoke

OBS 32.1.2 testing confirmed a multi-effect serial Rack produces audio, slot Enable/Bypass works, native VST3 UI opens, and the bounded P0 shutdown fix makes OBS close faster than before.

Third-party plug-ins

Compatibility still varies by plug-in.

A VST3 can use vendor-specific state, GUI and threading behavior. Passing the host qualification does not mean every commercial VST3 has been individually certified in Rack mode.

If a plug-in works in another host but fails here, report the exact plug-in name/version, OBS version, Windows version, whether the problem occurs in Single or Rack, and a minimal reproduction.
Rack resilience

What v0.6.0 does and does not promise.

✓
Missing preset slot preservation. A plug-in unavailable during preset load can remain visible as a pass-through Missing placeholder while the rest of the chain is reconstructed.
✓
Whole Rack process boundary. Third-party Rack code is outside OBS in one Rack helper process.
→
Future hardening: finer slot-correlated repeated-failure quarantine/recovery and a broader commercial multi-plug-in stress matrix remain roadmap work.
Report an issue

Useful compatibility reports are reproducible.

Open a GitHub issue with the plug-in vendor/name/version, OBS version, Windows version, Single vs Rack, steps to reproduce, and whether the native vendor editor was open.
