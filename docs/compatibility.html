Compatibility · v0.6.0 stable

Broad VST3 effect support, with explicit boundaries.

The project targets conventional Windows x64 VST3 audio effects. Compatibility is evidence-based, not implemented as a hard-coded vendor whitelist, and no responsible host can guarantee every VST3 implementation.

Real-machine evidence

Representative commercial VST3 effects have been part of project qualification.

Across the stable Single Host line and Rack development, real-machine qualification has included effects from vendors such as:

iZotope Ozone / RXFabFilterWavesKlevgrandNeuro AudioProcess Audio
These names are qualification examples, not an allowlist or guarantee. A different plug-in version, licensing layer, editor implementation or VST3 lifecycle behavior can still expose a vendor-specific compatibility issue.
Rack behavior

v0.6.0 Rack scope is intentionally serial.

FX

Effects only

Normal audio effects are eligible. Explicit instrument-only classes are not exposed as today's insert-effect workflow.

2CH

Mono / stereo

The stable scope is mono/stereo Float32. Advanced bus layouts and Float64 are future work.

→

Serial lane

Rack slots process in a defined serial order. Sidechain, arbitrary graph routing and parallel patchbay behavior are deliberately outside v0.6.0.

When a plug-in is missing or unhealthy

Compatibility failure should remain understandable and bounded.

✓
Missing Rack plug-ins can remain placeholders. The saved Rack definition does not need to be destructively rewritten just because a VST3 is temporarily unavailable.
✓
Invalid preset loads do not replace the current working Rack.
✓
Unavailable wet results fall back to dry/pass-through audio under the product's bounded realtime policy.
✓
Scanning is isolated from OBS so normal candidate discovery does not intentionally load every third-party module into the broadcast process.
Report a compatibility problem

Good reports become better regression tests.

Include Windows version, OBS version, exact VST3 product/version, Single Host vs Rack, reproduction steps, expected/actual behavior and relevant OBS logs. Do not attach commercial plug-in binaries unless their license explicitly permits redistribution.
