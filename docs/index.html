Two workflows

Keep the simple path simple. Use the Rack when the chain grows.

v0.6.0 ships both product surfaces in the same Windows package.

1FX

VST 3.x Plug-in

The proven one-effect workflow: automatic discovery, real vendor GUI, state persistence, isolated scanner/runtime and bounded recovery.

RACK

VST3 Rack

Build a serial multi-effect chain with add, replace, remove, reorder and bypass from a dedicated helper-owned graphical editor.

SAFE

Live-first boundary

Third-party plug-in code remains outside OBS. When a valid isolated wet result is unavailable, the design preserves dry/pass-through audio rather than deliberately blocking realtime processing.

Stable Rack v0.6.0

A professional serial Rack, not a DAW-sized node graph.

The Rack is deliberately focused on the workflow most streamers need: an ordered lane of audio effects with fast access to each native plug-in interface.

CHAIN

Build the lane

Add, replace, remove, reorder and bypass effects while stable slot identity and coherent topology publication protect the runtime contract.

UI

Real plug-in interfaces

The Rack Editor is isolated, and native vendor windows remain helper-owned rather than being injected into OBS.

SAVE

Recall your sound

Session Snapshot handles working-state recovery while named Rack presets provide independent reusable chains with save, load, rename, update and delete.

🛡
Built around failure boundaries

VST3 runtime, vendor UI and scanning are separated from the OBS process by architecture.

Reliability before feature count

The broadcast process should not own third-party VST3 code.

✓
Separate helpers. Single Host and Rack each use isolated helper-process boundaries.
✓
Isolated scanning. Candidate probing is kept outside OBS.
✓
Bounded realtime behavior. An unavailable wet result falls back to original dry/pass-through audio.
✓
Recovery and persistence. State checkpoints, Rack snapshots and bounded restart behavior are first-class product concerns.
Crash isolation is not a malware sandbox and is not a promise that Windows, OBS, drivers or hardware can never fail. Only install VST3 plug-ins from vendors you trust. Read the exact boundary →
Release confidence

Public binaries come from a repeatable release pipeline.

The final Rack integration candidate passed focused Rack regressions, main CI and Compatibility Test Build. The public release pipeline rebuilds against pinned OBS/libobs, runs Windows tests and scanner smoke, validates packaging and the Smart Installer, and publishes SHA-256 checksums beside the binaries.
