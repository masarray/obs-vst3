After v0.6.0

The Rack is shipped. Hardening continues.

The roadmap now separates delivered product capability from the next reliability and routing layers.

Stage 1 · Shipped

Safe Single VST3 Host. External host process, scanner, native vendor UI, state restore and dry fail-open behavior.

Stage 2 · Shipped in v0.6.0

Graphical VST3 Rack. Up to eight serial effects, browser, add/insert/reorder/bypass/replace/remove, vendor UI, Session Snapshot and named presets.

Stage 3 · Hardening

Rack resilience + qualification. Finer missing/repeated-failure slot correlation, quarantine/recovery and broader deterministic/commercial stress evidence.

Delivered in v0.6.0

Rack v2 product surface

The following items are no longer future roadmap promises.

UI

Graphical Rack Editor

Helper-owned professional dark editor with compact slot cards, catalog search, drag/reorder, health/latency status and keyboard/menu fallbacks.

VST

Vendor editors

Floating native VST3 editor windows per Rack slot while Rack DSP stays in the external helper.

P

Preset library

Save As, Load, explicit Update, Rename and Delete with independent working-copy semantics and Missing placeholders.

Next reliability work

Evidence before breadth.

→
Correlated slot failure recovery. Preserve good slots while distinguishing Missing, repeatedly crashing and ambiguous helper failures without restart storms.
→
Deterministic Rack torture matrix. Repeated add/remove/reorder/bypass, 1/2/4/8 effects, helper kills, corrupt state/presets, missing plug-ins and editor open/close cycles.
→
Broader commercial qualification. Expand evidence across representative real-world VST3 effects before making stronger compatibility claims.
→
Performance evidence. Track helper CPU, deadline misses, memory, hidden-editor cost and visible editor CPU/GPU at representative Rack sizes.
Later product layers

Explicitly not v0.6.0.

These features require new architecture or a larger product contract and are not implied by the current Rack.

Advanced routing

Parallel lanes, graph/patchbay workflows and sidechain routing.

MIDI / instruments

VST3 instruments, MIDI event routing and performance-oriented control.

Broader formats/platforms

Arbitrary multichannel, Float64 and non-Windows stable runtimes.

Roadmap items are direction, not release guarantees. Reliability, real-time safety and reproducible compatibility evidence take priority over adding a broad feature surface quickly.
