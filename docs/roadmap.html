Product roadmap · synchronized with v0.6.1

Stable Single Host. Durable serial Rack. Expand only without weakening the live-safety contract.

The roadmap is intentionally staged. New breadth matters only if realtime behavior, recovery, OBS integration, packaging and user workflow remain dependable enough for live use.

Stage 1

Safe VST3 Single Host — stable

The focused one-effect filter remains the simplest way to use a modern VST3 effect in OBS.

1FX

Simple workflow

Installed discovery, one selected effect and direct access to its native vendor interface.

ISO

Isolation

VST3 runtime and scanner stay outside the OBS process, with state persistence and bounded recovery.

DRY

Fail-dry

A missing/late isolated wet result does not justify deliberately stalling OBS's realtime audio path.

Stage 2 · v0.6.1

Safe VST3 Rack — stable and durable

v0.6.0 introduced the public serial Rack; v0.6.1 hardens working-state recall and split-component VST3 state safety after repeated real OBS restart testing.

RACK

SAVE

Automatic recall + presets

The current working Rack survives normal OBS restarts automatically, while named presets remain independent reusable chains.

Current Rack reliability contract

Persistence must not weaken realtime safety.

✓
CRC-protected atomic working-session writes with last-known-good recovery.
✓
DSP-safe state capture without a realtime-required control mutex.
✓
Dry-first restore followed by atomic whole-generation publication.
✓
Split controller/processor VST3 edits synchronized before state capture.
✓
Storage failure is surfaced as Needs Attention rather than silent nonpersistent operation.
Stage 3 · future

Routing, sidechain and advanced audio buses

Potential future work includes explicit routing, sidechain inputs, richer VST3 buses, parallel paths where justified, stronger multichannel handling and Float64 fallback. These are not v0.6.1 features.

Stage 4 · future

MIDI and VST3 instruments

Instrument hosting needs a real event/timing model—MIDI input, event buses, note/controller timing, sustain/pitch/modulation, state recovery and low-latency monitoring. It is intentionally separate from today's effects-only product scope.

Long-term

A professional OBS live-audio platform without becoming a DAW-sized default UI.

Potential directions include scene-aware presets, macro control, richer diagnostics, compatibility intelligence, signed releases, broader platform support and live-performance features—only when the underlying reliability model is preserved.

Roadmap items are direction, not guaranteed dates. The project intentionally prefers evidence-backed releases over shipping feature count.
