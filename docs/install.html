Smart Installer

Recommended for nearly everyone

1

Close OBS

Stop streaming/recording and close OBS Studio before replacing plug-in binaries.

2

Run Setup

Download OBS-Safe-VST3-Host-v0.6.1-Setup-x64.exe only from this project's GitHub Releases page.

3

Select OBS root

Choose the folder containing bin\64bit\obs64.exe. Normal, custom and portable-mode roots use the same product layout.

Windows may show Unknown publisher because the current package is not commercially Authenticode-signed. Do not disable Defender or SmartScreen globally. Use the official Releases page and verify SHA256SUMS.txt if you want an additional integrity check.
After installation

Choose the workflow that matches your chain

1FX

Single effect

Audio source → Filters → + → VST 3.x Plug-in. Select an installed VST3 effect, then open its vendor interface.

RACK

Multiple effects

Audio source → Filters → + → VST3 Rack. Open Rack, add effects, reorder/bypass them and open native vendor UIs when needed.

SAVE

Automatic recall

The latest working Rack is saved automatically for normal OBS restart continuity. Named presets remain independent reusable chains.

v0.6.1 Rack recall

No named preset is required just to survive an OBS restart.

Each VST3 Rack filter owns a durable working-session snapshot identified by its OBS source UUID. OBS save/close requests a bounded fresh state capture; the helper restores slow chains dry-first and publishes the complete restored generation only when it is coherent.

✓
Topology + bypass + VST3 state. The working chain is persisted as one coherent Rack session.
✓
Atomic + last-known-good. CRC-protected session writes preserve a recovery copy.
✓
DSP-safe capture. Realtime Rack processing does not wait on a control mutex while state is captured.
✓
Honest storage failure. If durable session storage cannot be established, the Rack remains dry and reports Needs Attention.

Check SHA-256 when desired

Every release includes SHA256SUMS.txt. In PowerShell:

Get-FileHash .\OBS-Safe-VST3-Host-v0.6.1-Setup-x64.exe -Algorithm SHA256

Compare the resulting hash with the installer entry in the release's SHA256SUMS.txt.
