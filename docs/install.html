v0.6.0 · Windows x64

Install once. Choose Single or Rack in OBS.

The v0.6.0 package installs the OBS module, the Single VST3 helper, the Rack helper and the isolated scanner.

Recommended — Smart Installer

  1. Close OBS Studio completely.
  2. Download OBS-Safe-VST3-Host-v0.6.0-Setup-x64.exe from GitHub Releases.
  3. Run the installer. Confirm the OBS Studio root folder when requested.
  4. Start OBS Studio.
A normal OBS root contains folders such as bin, obs-plugins and data. The installer remembers the validated root for later updates.

Installed files

Use one VST3 effect

  1. Open the Filters window for an OBS audio source.
  2. Add VST 3.x Plug-in.
  3. Keep Plug-in Source on Installed plug-ins.
  4. Choose the VST3 effect from the Installed Plug-in list.
  5. Use the plug-in UI button when you need its native editor.

Use VST3 Rack

  1. Open the Filters window for an OBS audio source.
  2. Add VST3 Rack.
  3. In Rack Properties, use Open Rack.
  4. Search the installed catalog and choose Add Effect.
  5. Add more effects as needed. Reorder, bypass/enable, replace or remove slots from the Rack Editor.
  6. Use Open UI on a slot to open the VST3 vendor editor.
  7. Use Save As to store the current Rack as a named preset.

The Rack is serial: OBS input → Slot 1 → Slot 2 → … → Slot 8 → OBS output. Closing the Rack Editor window does not stop the Rack audio processing.

Rack preset behavior

  • Save As creates a new saved preset identity.
  • Selecting a preset loads an independent copy into the working Rack.
  • Normal edits after load do not change the saved preset.
  • Update is the only normal action that writes the working Rack back to that preset.
  • Rename preserves preset identity/content.
  • Delete requires intentional confirmation.
  • If a referenced plug-in is unavailable, the preset can retain a Missing/pass-through placeholder instead of silently discarding that slot.

Portable ZIP

Download OBS-Safe-VST3-Host-v0.6.0-Windows-x64-Portable.zip and extract its contents directly into the OBS root. Keep the included README-FIRST.txt and UNINSTALL-MANUAL.cmd.

Verify download integrity

The Release also contains SHA256SUMS.txt. On PowerShell:

Get-FileHash .\OBS-Safe-VST3-Host-v0.6.0-Setup-x64.exe -Algorithm SHA256

Windows warning

Release binaries are currently not commercially Authenticode-signed, so Windows may show Unknown publisher or a SmartScreen reputation warning. Do not disable Windows security globally. Download from the official GitHub Release and verify the checksum when desired.

Uninstall

For the Smart Installer package, use the registered Windows uninstaller. For a manual portable installation, close OBS and run UNINSTALL-MANUAL.cmd from the OBS root.

If a plug-in does not appear

  • Confirm it is a 64-bit VST3 audio effect.
  • Refresh the plug-in list / Rack catalog.
  • Check normal Windows VST3 locations and the vendor's installation path.
  • Remember that instruments, MIDI-only plug-ins and unsupported bus layouts are outside the v0.6.0 scope.
