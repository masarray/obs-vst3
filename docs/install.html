Guided troubleshootingTroubleshooting terpandu

Start from the symptom you can see. Do not reinstall everything blindly.Mulai dari gejala yang terlihat. Jangan langsung instal ulang semuanya tanpa arah.

Each card corresponds to one checkpoint in the install path. Fix the first failed checkpoint before moving to the next one.Setiap kartu sesuai dengan satu checkpoint pada jalur instalasi. Perbaiki checkpoint pertama yang gagal sebelum lanjut ke berikutnya.

A. “VST 3.x Plug-in” is missing from OBSA. “VST 3.x Plug-in” tidak muncul di OBS

INSTALL
  1. Confirm you restarted OBS after Setup.Pastikan OBS sudah dijalankan ulang setelah Setup.
  2. Run Setup again and verify the selected root contains bin\64bit\obs64.exe.Jalankan Setup lagi dan pastikan root yang dipilih berisi bin\64bit\obs64.exe.
  3. If you have more than one OBS installation, make sure Setup targets the same one you actually launch.Jika Anda memiliki lebih dari satu instalasi OBS, pastikan Setup menarget instalasi yang benar-benar Anda jalankan.
  4. Do not select bin\64bit itself; select its OBS root parent.Jangan pilih bin\64bit itu sendiri; pilih OBS root induknya.
Expected result:Hasil yang diharapkan: VST 3.x Plug-in appears in the audio-filter menu.muncul di menu audio filter.

B. The filter exists, but the VST3 list is emptyB. Filter ada, tetapi daftar VST3 kosong

SCAN
  1. Choose Installed plug-ins under 1. Plug-in Source.Pilih Installed plug-ins pada 1. Plug-in Source.
  2. Click Refresh Plug-in List and wait for discovery to finish.Klik Refresh Plug-in List dan tunggu discovery selesai.
  3. Confirm the product you installed is a VST3 audio effect, not only a VST2 plug-in or an instrument-only VST3.Pastikan produk yang Anda instal adalah efek audio VST3, bukan hanya plug-in VST2 atau VST3 yang hanya instrument.
  4. If needed, use Browse a .vst3 file… to test a known plug-in bundle directly.Jika perlu, gunakan Browse a .vst3 file… untuk menguji bundle plug-in yang sudah diketahui secara langsung.
Expected result:Hasil yang diharapkan: at least one VST3 audio effect becomes selectable under 2. Installed Plug-in.minimal satu efek audio VST3 dapat dipilih pada 2. Installed Plug-in.

C. The VST3 is listed, but its interface does not openC. VST3 terdaftar, tetapi interfacenya tidak terbuka

PLUGIN
  1. Test a second known VST3 effect. This separates a host-wide problem from one vendor plug-in.Uji efek VST3 lain yang diketahui. Ini membedakan masalah host secara umum dari masalah satu plug-in vendor.
  2. If only one plug-in fails, check the compatibility boundary before reinstalling the host.Jika hanya satu plug-in gagal, cek batas kompatibilitas sebelum menginstal ulang host.
  3. A plug-in without a usable native editor may expose fallback controls instead of a vendor window.Plug-in tanpa native editor yang dapat digunakan mungkin menampilkan fallback controls sebagai pengganti jendela vendor.
Do not reinstall blindly:Jangan instal ulang tanpa arah: if another VST3 works, installation itself is already proven.jika VST3 lain bekerja, instalasi host sebenarnya sudah terbukti benar.

D. The interface opens, but the sound does not changeD. Interface terbuka, tetapi suara tidak berubah

AUDIO
  1. Make one intentionally obvious change in the plug-in, such as a strong gain or EQ move.Buat satu perubahan yang sengaja jelas pada plug-in, misalnya perubahan gain atau EQ yang besar.
  2. Toggle the OBS filter OFF / ON while monitoring the same source.Matikan/nyalakan filter OBS sambil memonitor sumber audio yang sama.
  3. Verify you are listening to the source that owns this filter, not another microphone or monitor path.Pastikan yang Anda dengarkan adalah sumber audio yang memiliki filter ini, bukan mikrofon atau jalur monitor lain.
  4. Try a second simple effect before moving to Rack.Coba efek sederhana kedua sebelum pindah ke Rack.
Success criterion:Kriteria berhasil: OFF = original and ON = audibly processed.OFF = original dan ON = terdengar terproses.

E. Single Host works, but Rack does notE. Single Host bekerja, tetapi Rack tidak

RACK
  1. Treat installation as successful. Do not keep reinstalling the OBS module.Anggap instalasi berhasil. Jangan terus menginstal ulang modul OBS.
  2. Add VST3 Rack as a separate filter and click Open Rack.Tambahkan VST3 Rack sebagai filter terpisah lalu klik Open Rack.
  3. Start with one slot, confirm audio, then add more effects one by one.Mulai dengan satu slot, pastikan audio bekerja, lalu tambah efek satu per satu.
Key distinction:Pembeda utama: Single Host success proves the core install and VST3 discovery path.Keberhasilan Single Host membuktikan jalur instalasi inti dan discovery VST3.

F. Update installed to the wrong OBS copyF. Update terpasang ke instalasi OBS yang salah

TARGET
  1. Setup remembers the last validated OBS root for future upgrades.Setup mengingat OBS root terakhir yang tervalidasi untuk upgrade berikutnya.
  2. If you changed OBS installations, run Setup interactively and select the new root that contains bin\64bit\obs64.exe.Jika Anda berganti instalasi OBS, jalankan Setup secara interaktif dan pilih root baru yang berisi bin\64bit\obs64.exe.
  3. After installation, restart the OBS copy you actually targeted.Setelah instalasi, jalankan ulang OBS yang memang Anda target.
Why this matters:Mengapa ini penting: multiple OBS installations can make a correct installation look missing in the other copy.beberapa instalasi OBS dapat membuat instalasi yang benar terlihat seolah hilang pada copy OBS lain.

Still stuck? Report one reproducible failure.Masih gagal? Laporkan satu kegagalan yang dapat direproduksi.

Include the exact checkpoint that failed, Windows version, OBS version, whether Single Host or Rack is affected, VST3 vendor/name/version, and the relevant OBS log. That is much more useful than “plugin does not work”.Sertakan checkpoint yang gagal, versi Windows, versi OBS, apakah Single Host atau Rack yang terdampak, vendor/nama/versi VST3, serta log OBS yang relevan. Informasi ini jauh lebih berguna daripada sekadar “plugin tidak bekerja”.

Normal OBS restarts can restore the current working Rack state automatically.Tambahkan VST3 Rack setelah satu efek sudah bekerja di Single Host. Safety boundaryBatas keamanan

The host isolates third-party VST3 runtime work from OBS, but isolation is not a malware sandbox. Install plug-ins only from vendors you trust and review the exact failure boundary before production use.Host mengisolasi runtime VST3 pihak ketiga dari OBS, tetapi isolasi bukan malware sandbox. Instal plug-in hanya dari vendor yang Anda percaya dan pahami batas kegagalannya sebelum dipakai untuk produksi.
